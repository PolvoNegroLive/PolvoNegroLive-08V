# Como contribuir

1. Abra uma issue descrevendo o problema ou a melhoria.
2. Preserve os recursos existentes e a compatibilidade com Windows 10/11 (64 bits).
3. Rode os testes: `scripts\TESTES.bat` ou `python -m unittest discover -s tests -v`.
4. Atualize o `CHANGELOG.md` e a documentação.
5. Não inclua chaves, tokens, logs pessoais ou arquivos de `%APPDATA%\PolvoNegroLive`.
