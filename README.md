# PolvoNegroLive-01V
🐙 Polvo Negro Live — infraestrutura open source e modular de mídia para Windows, criada para captura, processamento, gerenciamento, distribuição e retransmissão de vídeo e áudio. Foco em baixo custo, aproveitamento do hardware disponível, portabilidade, controle e escalabilidade de um computador para múltiplos nós.
